# NDM Lab UI

Простой веб-интерфейс для просмотра логов в реальном времени. 🔗 [Репозиторий бакенда](https://github.com/gorslawa2/test-ndm-ng4.git)

## Что внутри

- `docker-compose.yml` — поднимает контейнер с Python и nginx
- `html/index.html` — фронтенд (HTML + JS)
- `html/stream.py` — мини-сервер на Python, отдаёт логи через API
- Логи берутся из `/home/gor/test-ndm-v12/logs/hop_events.log` на хосте

## Как запустить

```bash
docker-compose up -d
```

После запуска:
- Веб-интерфейс: http://localhost:8085
- API логов: http://localhost:8086/api/logs

## Как работает

`stream.py` слушает GET-запросы на `/api/logs`, читает лог-файл с указанной позиции (параметр `since`) и возвращает новые строки в JSON. Фронтенд периодически опрашивает API и дописывает свежие логи на страницу.

Всё работает в одном контейнере на базе `python:3-alpine`. 

## Замечания

- Путь к логам захардкожен в `stream.py` — если нужно, поправить там же
- Том с логами монтируется read-only, так что случайно ничего не испортится
- Скрипт перезапускается автоматически при падении (`restart: unless-stopped`)
